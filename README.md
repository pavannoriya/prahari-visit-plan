# Prahari Visit Plan

Daily center visit plan banane ke liye alag app.

## Features
- Prahari login (phone se direct, VPN on rakho)
- Audit select karo
- Auto data fetch: centers + members + disbursements
- Score: (New Members x 2) + Members
- Daily plan rules:
  - 1 staff per day
  - Centers Mon-Fri only (Saturday ko meeting nahi)
  - Min target = working days x 4
  - Daily count flexible (4-7)
  - 5 din me kam se kam 4 alag staff
  - New member = pichhle mahine ka disbursement
- Gemini se plan review + suggestions
- Plan share karo (WhatsApp/text)

## Setup
1. App kholo
2. Prahari username/password daalo
3. Gemini API key daalo (free tier: aistudio.google.com)
4. VPN (InstaSafe) ON rakho
5. Audit chuno → Plan banao

## Security
- Password/Gemini key sirf phone me save hoti hai (DataStore)
- Kabhi code me ya GitHub pe save nahi hoti
- Test ke baad password change kar lena
